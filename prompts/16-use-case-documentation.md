## Assistant
Added a new "Use Case Documentation" generation option that produces one Markdown file per API operation, downloadable individually or included in the ZIP.

### New file: `src/app/services/use-case-generator.service.ts`
Injectable service that takes a `ParsedSpec` and produces `GeneratedFile[]` under `docs/use-cases/`.

For each operation across all tags it generates a Markdown file (`{operationId}.md`) containing:

1. **Title** — the operation `summary`, or PascalCase `operationId` as fallback
2. **Method and path** — e.g. `**Method:** \`GET\`` / `**Path:** \`/pets/{petId}\``
3. **Parameters section** — separate tables for path params and query params (name, type, required)
4. **Request Body section** — type name when a request body is present
5. **Response section** — type name when a response type is present
6. **C# Controller Code** — a `\`\`\`csharp` fenced block with the exact method signature that would be generated by `CsharpGeneratorService`, including the HTTP verb attribute, route, `[FromRoute]`/`[FromQuery]`/`[FromBody]` parameters, return type (`ActionResult<T>` or `IActionResult`), XML doc summary, and `throw new NotImplementedException()` stub
7. **Referenced DTOs** — a `\`\`\`csharp` fenced block per referenced schema (records and enums), resolved recursively through property `$ref` chains, deduplicated

The service reuses `CsharpGeneratorService.toCsType()` for consistent type rendering and duplicates only the two small private helpers (`toPascalCase`, `capitalize`) it needs internally.
